## screenshot-translation

一个使用 Electron、React 和 TypeScript 构建的桌面 AI 英语学习助手，帮助中文母语者从看懂英语到自然开口。

## 功能特性

- 快速截图屏幕区域

- 图片文字识别 (OCR)

- 调用 **AI 引擎**将识别出的文字翻译成目标语言

- 在截图区域附近显示翻译结果

- 输入中英文进行互译，并朗读原文或译文

- 分析英文句子的结构与表达

- 通过本地英语语音识别与 AI 进行实时口语对话

## 项目搭建

### Install

```bash
$ pnpm install
```

### Development

```bash
$ pnpm dev
```

### Build

```bash
# For windows  需要管理员权限
$ pnpm build:win

# For macOS
$ pnpm build:mac

# For Linux
$ pnpm build:linux
```

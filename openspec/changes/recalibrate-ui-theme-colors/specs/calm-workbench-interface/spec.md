## MODIFIED Requirements

### Requirement: 克制的语义强调
系统 SHALL 使用石墨中性色建立页面、侧栏、卡片、边框和普通内容层级，并 SHALL 使用单一矿物蓝强调色表达主操作、当前选择和键盘焦点。浅色与深色主题中的强调状态 MUST 保持相同语义，普通表面不得因大面积带有强调色色相而削弱主操作辨识度。

#### Scenario: 主操作与次要操作并存
- **WHEN** 页面同时显示主操作与次要操作
- **THEN** 主操作使用唯一的矿物蓝高强调外观，次要操作使用中性或淡强调外观且不会呈现相同的实色重量

#### Scenario: 区分连续表面
- **WHEN** 页面同时显示背景、侧栏、卡片或弹出表面
- **THEN** 各表面通过石墨中性色的明度层级清晰区分，且不会形成大面积青绿色偏色

#### Scenario: 显示语义错误
- **WHEN** 页面需要展示错误或破坏性操作
- **THEN** 系统使用独立的语义错误样式，且不会把错误误表示为品牌强调状态

#### Scenario: 切换明暗主题
- **WHEN** 用户在浅色、深色或跟随系统主题之间切换
- **THEN** 主操作、当前选择、悬停和键盘焦点在对应主题中保持可辨识且语义一致

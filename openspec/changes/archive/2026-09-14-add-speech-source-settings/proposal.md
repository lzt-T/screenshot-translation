## Why

目前所有文本朗读都依赖 Kokoro 本地合成，用户无法根据启动速度、离线需求和音色偏好选择其他来源。增加统一的语音来源设置，让翻译、学习与对话中的朗读使用同一套偏好。

## What Changes

- 设置页新增「语音播放」分组，提供浏览器语音、Kokoro 本地语音、第三方语音服务三种来源，默认保留 Kokoro。
- 所有来源固定正常语速，不提供语速配置；浏览器与 Kokoro 提供音色选择和试听。
- 浏览器自动模式优先匹配文本语言；列表为空或无匹配音色时设置目标语言并交给浏览器选择，不直接报错。明确指定音色仍严格匹配，切换音色清除旧试听错误。
- 第三方首批接入 MiMo、OpenAI、Azure Speech、ElevenLabs 和阿里云百炼。按服务商展示 API 地址、凭据、模型、音色及必要地域等字段，分别保存配置并支持试听；按各自官方语音协议实现，不假定协议兼容。
- 五家第三方的已知模型和音色提供预置下拉选择及自定义输入；Azure 不增加模型，ElevenLabs 音色保留账号 Voice ID 输入。目录按模型关联，保留旧配置及切换模型前的音色，对已知不兼容组合提示重选并禁止试听。
- 仅展示当前来源相关配置，切换来源保留各自配置，持久化并在后续朗读生效。
- 统一接入现有朗读入口，保留停止、抢占、结束回调和对话续接；来源失败时明确提示，不自动回退。

## Capabilities

### New Capabilities
- `speech-source-settings`: 语音来源配置、持久化、音色选择、正常语速、试听、统一播放与失败行为。

### Modified Capabilities
无。现有对话模式和界面规格的行为继续保留，新增语音来源通过统一朗读入口提供。

## Impact

- 设置页及 `useLocalForage` 设置加载和保存；语音相关类型与 IPC。
- `src/utils/speak.ts` 的调度、取消与缓存，Kokoro Worker 的音色参数。
- 新增浏览器语音适配和主进程五个第三方服务适配，使用服务商函数分发表与字段配置表，复用现有音频播放和网络配置能力。
- 翻译、学习、对话和临时窗口的既有朗读调用点需要核对一致性；不改变语音识别。
- 第三方语音需要网络和用户凭据；浏览器音色需要在目标 Electron 运行时验证。无需引入 Vue 或复制 TypeWords 源码。
